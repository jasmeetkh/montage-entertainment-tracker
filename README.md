# 🎬 Montage — Entertainment Tracker

A cinematic web app to track movies, shows and anime 
with live analytics and AI recommendations.

## Built With
- Google Stitch (UI Design)
- Google AI Studio + Gemini (Development)
- TMDB API (Movie Data & Posters)
- React + TypeScript

## Features
- Track movies, shows and anime
- Live analytics dashboard with genre charts
- TMDB real poster integration
- AI powered recommendations
- Trending today section
- Responsive on mobile and desktop
